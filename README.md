# Zero-OC Toolkit Releases

Zero-OC Toolkit 免费公共版的官方下载与自动更新仓库。

## 下载

请从右侧 **Releases** 下载最新的 Windows x64 安装包。安装包包含 16 款已获授权的第三方工具，默认安装到 `D:\Zero-OC Toolkit`。

## 自动更新

从 v0.3.0 起，安装版会自动检查本仓库中已正式发布的最新版本。v0.2.7 及更早版本需要手动安装一次 v0.3.0。

## 安全校验

每个版本提供 `SHA256SUMS.txt`。当前安装包尚未配置商业代码签名，Windows SmartScreen 可能显示“未知发布者”。

## 风险提示

超频和压力测试可能造成高温、系统不稳定或数据丢失。使用前请保存工作并确认散热、电源和硬件状态正常。第三方软件权利归各自权利方所有。
